Petits scripts Python pratiques

Des scripts créés avec l'aide de l'IA pour automatiser des tâches du quotidien : ajouter des signets à de gros PDF (recueils de partitions notamment), alléger des fichiers scannés, extraire des pièces jointes, créer des arborescences de dossiers…

Contrairement aux outils web d'artifacts, ces scripts s'exécutent sur votre ordinateur avec Python. La plupart ouvrent une petite interface graphique dans votre navigateur.

🔒
Vos fichiers restent chez vous

Tous les traitements ont lieu sur votre ordinateur. Les interfaces Gradio et Streamlit s'affichent dans le navigateur, mais elles sont servies par votre propre machine (adresse 127.0.0.1) : aucune donnée n'est envoyée sur Internet.

Démarrage rapide

  1. Installez Python 3.10 ou plus récent. Sous Windows, cochez « Add Python to PATH » pendant l'installation.
  2. Téléchargez le script voulu (bouton Télécharger de sa carte) dans un dossier.
  3. Ouvrez un terminal dans ce dossier, installez les bibliothèques indiquées sur la carte, puis lancez le script : 
    pip install pypdf gradio
python pdf-insertion-signets.py
  4. Pour les scripts Gradio, ouvrez l'adresse affichée dans le terminal (http://127.0.0.1:7860). Les applications Streamlit se lancent avec streamlit run app.py.

Aucun script ne correspond à votre recherche.

Bibliothèques nécessaires

Toutes sont libres et s'installent avec pip install ….
